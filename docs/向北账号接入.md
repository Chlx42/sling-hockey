# 向北账号接入

从广场通过 `?northward=1` 进入时，网页自动生成 state 与 PKCE 校验值并跳转固定官网启动页；返回后清除 URL 片段，在本游戏后端兑换一次性码。游戏不接收向北主 token。普通分享与旧 IP 入口继续支持游客。

游戏服务配置 `NORTHWARD_EXCHANGE_URL`、`NORTHWARD_GAME_ORIGIN` 和至少 32 字符的 `NORTHWARD_GAME_SECRET`。配置缺失时，账号能力关闭，保持原匿名玩法；生产只允许 HTTPS 交接。环境文件由 systemd 读取，不提交仓库。

会话最长 8 小时，Cookie 使用 HttpOnly、Secure、SameSite=Lax，不设置 Domain。每次从广场进入先清理上一个账号。成绩归属以服务端会话为准，客户端 UID 不作为认证凭据；历史匿名记录保留，不自动合并。

部署必须包括新增的 `northward-auth`、`northward-session` 服务模块和浏览器 `northward-login` 模块。完整配置、发布顺序、验证和回退见 Northward Ops 的 `docs/广场游戏账号接入.md`。

验证应区分单元测试、真实服务 loopback 联调、浏览器回归与生产真机；不能用已有 HTTP IP 首页成功代替新域 TLS、账号或联机验收。
